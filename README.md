# TO-DO List App

A simple **TO-DO List web application** that allow user to **add, manage, and delete tasks** using **sticky notes UI**. THis project is bilt using **HTML, CSS and JavaScript**.

## Features

- **Add new tasks** - using an input field.
- **Random background color** - for each new sticky note.
- **DElete tasks** - by clicking the "X" button.
- **Sticky note UI** - for an engaging experience.

## Technologies Used

- **HTML & CSS** - For Layout & styling.
- **JavaScript** - Functionaliy and DOM manipulation.

## How to Use

1. Type your task in the input field.
2. Click the **"Add"** button to create a sticky note.
3. Click the X **delete button** on a sticky note to remove it.
